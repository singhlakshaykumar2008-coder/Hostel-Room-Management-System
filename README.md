●● Overview of the project ●●

The Hostel Room Management System is a simple python based project designed to manage students information in hostel rooms and gives us the necessary information names of students living in that room and provide and interface to change and update students rooms and to remove name from a room.
This project demonstrates the use of Python concepts such as dictionaries, lists, loops, conditional statements, functions, user input, and data manipulation.

The system can be useful for managing hostel room records in colleges and universities.

●● Features ●●
The project provides the following features:

● Find Students by Room Number
Enter a room number to see the students currently living in that room.

● Update Student Name
Change or correct the name of an existing student.

● Change Student Room
Move a student from one hostel room to another.

● Add New Student
Add a new student to a particular hostel room.

● Display All Rooms
Display all rooms and the students assigned to them.

● Exit
Safely exit the program.
