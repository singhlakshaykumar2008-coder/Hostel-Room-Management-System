1. Problem Statement:-

• As we know that todays generation and various day to day life things are shifted towards developing technology. For an example:-
• Managing hostel room and student information manually can be time-consuming and may lead to errors in maintaining records.
Keeping records on pen and paper may lead to information leak or data redundancy
• The Hostel Room Management System is developed using Python to provide a simple solution for managing hostel room records. \
The system allows users to search for students by room number, update student names, add new students, and change the room assigned to a student.
3. Scope of the project:-

•The scope of this project is to provide a basic computer-based system for managing hostel room and student information.
The system can be used to:

• Store student names according to their hostel rooms.
• Search for students using a room number.
• Add new students to a hostel room.
• Update the name of an existing student.
• Change a student's room assignment.
• Display all available rooms and their students.
• Reduce the need for maintaining hostel records manually.

In the future, the project can be expanded by adding a database, login system, room capacity management, hostel block management, and a graphical user interface.

4. High-Level Features:-

The major features of the Hostel Room Management System are:

• Room-Based Student Search

Users can enter a hostel room number and view the names of students living in that room.

• Add New Student

Users can add a new student's name and assign the student to a particular hostel room.

• Update Student Name

The system allows users to correct or update the name of an existing student.

• Change Student Room

Users can move a student from one hostel room to another by entering the student's name and the new room number.

• Display All Rooms

The system can display all stored hostel rooms along with the students assigned to each room.

• Exit System

Users can safely exit the program through the main menu.
